# Changelog

## 1.7.0 — 2026-09-18

First public open-source edition of Douyin Director.

- Preserve video download, speech evidence, all-frame visual analysis, reports, rewriting and optional Feishu integration.
- Default to local direct provider calls with no hosted account or credit requirement.
- Add complete searchable settings, masked/revealable secrets and encrypted overrides.
- Separate open-source user data from the existing desktop edition.
- Use a configurable, user-installed FFmpeg executable; make Python fallback optional.
- Provide public-only packaging defaults, offline regression tests, Windows UI checks and CI.
- Include MIT licensing, configuration/development/privacy documentation and contribution templates.
