# 数据与隐私

工作台启动本地 API，模型与飞书请求由本机发起。没有项目维护者提供的中转云服务。执行分析时，必要的音频、帧图片和文本会发送到你配置的供应商；连接飞书并执行入库时，素材会写入你自己的飞书多维表格。

Windows 开源版资料目录默认是 `%APPDATA%\douyin-director-opensource`：

- `workbench-settings.bin`：系统加密的设置覆盖，含你保存的模型 Key。
- `material-library.bin`：系统加密的个人飞书连接。
- `Partitions/` 等 Electron 会话文件：抖音登录状态。
- `jobs/` 或你选择的任务目录：下载视频、音频、抽帧、报告及诊断信息。
- `startup.log`：启动状态与错误。

数据存储管理可以查看或清理任务缓存。`KEEP_VIDEO=false` 会在分析完成后清理原视频和音频，保留帧与结果。卸载默认保留个人资料以避免误删；不再需要时可在关闭程序后自行删除对应资料目录。

这些文件均不应上传 GitHub，包含加密凭据的文件也不例外。诊断信息可能含作品标题、链接、任务标识或本机路径；分享前需检查。项目仓库的测试只使用模拟数据，不需要提交真实用户资料。
