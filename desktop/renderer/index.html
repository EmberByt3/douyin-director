飞书素材库接入指南

从零连接到工作台

按顺序完成 7 步，通常只需要配置一次。

先看结论

你需要一个飞书企业自建应用、一张空白多维表格，以及该表格的管理权限。工作台会自动创建 5 张表和 40+ 个字段，无需手工建表。

无需机器人无需事件订阅无需回调地址无需公网服务器
准备 创建应用 开通权限 发布应用 创建 Base 连接工作台 验收
01

准备飞书账号和权限

  1. 使用准备存放素材库的飞书企业账号登录。
  2. 确认自己可以创建企业自建应用；没有权限时，让企业管理员在飞书管理后台开放应用创建权限，或由管理员协助创建。
  3. 应用和多维表格必须位于同一个飞书企业。跨企业的应用无法直接访问另一家企业的文档。
个人测试建议先用一张全新的空白多维表格，不要启用高级权限，排查最省事。
02

创建企业自建应用

  1. 点击下方按钮进入飞书开放平台，登录后选择当前企业。
  2. 点击“创建企业自建应用”，填写应用名称、描述和图标。
  3. 进入“凭证与基础信息”，复制 App ID 和 App Secret。App ID 通常以 cli_ 开头。
App Secret 相当于密码，不要发到群里、截图公开或写进共享文档。工作台会使用 Windows 安全存储在本机加密保存。
03

开通正确的 API 权限

在应用左侧进入“权限管理”，搜索并开通下面的权限。优先使用直接 /base/ 链接，只需要第一项。

必选 查看、评论、编辑和管理多维表格 bitable:app

用于读取 Base，并创建表、字段和记录。

按需 查看知识空间节点信息 wiki:node:read

仅在粘贴的链接包含 /wiki/ 时需要。

不要只开“查看多维表格”这类只读权限，否则测试可能通过，但初始化时无法建表或写入。
04

创建版本并发布

  1. 进入“版本管理与发布”，点击“创建版本”。
  2. 填写版本号，例如 1.0.0，确认可用范围包含自己。
  3. 提交发布；企业开启审核时，由管理员在管理后台批准。
  4. 看到版本状态为“已发布”后，再继续下一步。
以后每次新增或修改权限，都要重新创建版本、发布并完成审批。只在权限页勾选但未重新发布，权限不会生效。
05

创建空白 Base，并授权给应用

  1. 在飞书“云文档”中点击“新建” → “多维表格”。
  2. 可以命名为“我的编导素材库”，保留空白即可，不需要手工添加字段。
  3. 打开多维表格右上角“…” → “更多” → 添加文档应用，搜索刚才创建的应用。
  4. 把应用添加到文档，并授予可管理权限。
  5. 从浏览器地址栏复制直接包含 /base/ 的完整链接。直接 Base 链接比 Wiki 链接更稳定、所需权限更少。
API 权限和文档权限缺一不可 应用后台开通权限，决定“能调用什么接口”；表格里添加文档应用，决定“能访问哪一张表”。
搜不到应用时，先确认应用已发布、应用和 Base 属于同一企业，并刷新多维表格页面后重试。
06

连接到编导工作台

  1. 回到“素材库”页，在“我的飞书素材库”填写 App ID。
  2. 填写 App Secret。已经连接过时可以留空，沿用本机安全存储的值。
  3. 粘贴刚才复制的空白 Base 完整链接。
  4. 先点击“测试连接”，确认凭证和 Base 可访问。
  5. 再点击“连接并初始化”。工作台将自动创建或修复“视频主表、素材片段表、镜头执行表、产品表、数据复盘表”。
  6. 看到“初始化完成”后，点击“打开素材库”检查表结构。
07

做一次完整验收

完成后，之后粘贴新素材进行分析时，报告生成和个人素材入库会在同一任务中执行；写入失败时可在报告页点击“重新入库”。

连接失败时

按报错文字快速排查

飞书应用认证失败

检查 App ID、App Secret 是否复制完整，前后不要有空格；Secret 重置后必须填写新值；并确认应用版本已发布。

Permission denied / 99991663

通常是未开通 bitable:app，或修改权限后没有重新发布版本并完成企业审批。

Permission denied / 1254302

通常是 Base 没有添加该应用为“文档应用”，或只给了只读权限。回到 Base 授予应用可管理权限。

BaseTokenNotFound / 1254040

链接或 token 不正确。重新从目标多维表格地址栏复制完整的 https://.../base/... 链接。

Wiki space permission denied / 131006

当前使用的是 /wiki/ 链接。推荐改用直接 /base/ 链接；否则开通 wiki:node:read 并给应用知识库节点访问权限。

测试成功，但初始化建表失败

说明凭证可用，但写权限不足。确认使用的是“查看、评论、编辑和管理多维表格”，并确认文档应用权限为可管理。

安全提醒 每位用户只连接自己的应用和 Base。不要共用 App Secret；离开电脑前可在绑定区点击“断开”，清除本机保存的凭据。
